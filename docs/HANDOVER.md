# 订阅集 SubNest · 交付说明

已完成可运行的中英文商城和管理后台。项目位于 `/root/member-store`，名称暂定「订阅集 SubNest」。

## 打开网站

域名已切换至订阅集，HTTPS 服务已启动：

- 商城：<https://shop.example.com>
- 管理后台：<https://shop.example.com/#admin>
- 域名原先连接的 ClearCount 网站已解除该域名绑定；原站点文件保留。HTTP 会自动跳转 HTTPS。
- 后台密码保存在项目 `.env` 的 `ADMIN_PASSWORD` 中。源码压缩包不包含这台机器的密码或数据库；在其他机器运行 `npm run setup` 会生成新的密码。

商城由 `subnest.service` 系统服务运行，已设置开机启动和异常重启。停止：`systemctl stop subnest`，重启：`systemctl restart subnest`。本机上游仍只监听 `127.0.0.1:4180`，公网入口由 Nginx 提供。

## 可以使用的功能

- 中英文切换、手机布局、搜索分类、商品详情和下单。
- 支付宝、微信、银行卡、币安的人工收款渠道。
- 客户提交付款参考号，商家核实到账后才采购或发货。
- ProdSeller 商品同步、余额查询、采购、自动交付和邮箱开通进度。
- 自定义商品、中英文介绍、售价、上下架、卡密库存与人工交付。
- 客户通过私密查询凭证领取商品，可以复制或下载凭证。
- 后台支持多个供货商和连接预设，现有 QuantumVault、Pixel / SheerID 与 ProdSeller 兼容预设。API Key 加密保存，保存后不能查看。

## 目前的运行状态

**当前网站已连接 ProdSeller 的真实商品目录，付款方式为人工核款。** 接口验证和商品同步不采购、不扣款；实际采购在商家确认到账后执行。启用真实收款前，需配置收款渠道并核对商品售价。

你已经选择先用人工确认收款，因此当前没有接支付宝/微信/币安自动支付网关。后台填好收款信息后，实际到账由你核实。会员激活或交付异常可在后台核查并重试；退款由店铺在收款渠道人工办理。

登录后台的「供应商连接」可添加 QuantumVault 或 ProdSeller 兼容供货商。验证仅同步商品，不采购、不扣款；密钥加密保存在数据库。QuantumVault、Pixel 和 SheerID 不支持安全重试，单次限购一件，超时须在供货商后台核对并使用订单号恢复。Pixel / SheerID 任务默认下架，用户确认的换算为 1 coin = 1 元人民币；经人工核款后，客户自愿提交的任务资料加密暂存，发送供货商或发生错误后清除。配置收款渠道、核对汇率和售价后，再进行真实联调。域名 HTTPS 已配置。

如果先销售自己的卡密，无需供应商 Key，设为 `PRODSELLER_MODE=demo`、`PAYMENT_MODE=manual` 即可只展示自营商品。
